적용 단계

단계할 일누구와언제까지
1. 점검2일차 3교시 개인정보·보안 점검표를 모두 확인  
2. 협의기관 보안 담당·개인정보 담당과 사용 여부 협의(실제 데이터를 넣기 전)  
3. 시범가상 데이터로 동료 2~3명이 1주일 써 보기, 불편한 점 모으기  
4. 보완시범에서 나온 점 고치기(앱 문구, 칸, 알림 대상)  
5. 운영기관 설치형 n8n 또는 승인된 환경으로 옮겨 실제 사용  
실제 데이터는 2단계 협의 뒤에 교육용 n8n Cloud 체험 계정과 개인 구글 계정에 실제 민원·개인정보를 넣지 않습니다. 운영 환경은 기관의 승인을 받아 정합니다.
