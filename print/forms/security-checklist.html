A. 누가 볼 수 있나 (앱 공유)

  1. [됨 · 아직 · 모름] 공유 링크는 필요한 사람에게만, 보기 권한으로 주었다.
  2. [됨 · 아직 · 모름] 공유받은 사람은 앱 코드를 볼 수 있다는 것을 안다. 코드에 비밀값·실제 개인정보·내부 문서가 없다(Code 탭에서 확인).
  3. [됨 · 아직 · 모름] 앱 코드에 든 n8n 주소(Production URL)는 공유받은 사람도 볼 수 있다. 주소가 알려지면 누구나 요청을 보낼 수 있고, Allowed Origins(CORS)로는 막지 못한다. 실제 운영 전 인증 방법을 기관 보안 담당과 정한다.
  4. [됨 · 아직 · 모름] 공유 앱에서 쓰는 AI 사용량은 모두 만든 사람(내 계정) 한도에서 빠진다.

B. 비밀값

  1. [됨 · 아직 · 모름] API 키·봇 토큰·비밀번호를 앱 코드나 주문 문장(프롬프트)에 쓰지 않았다. AI Studio는 Settings → Secrets, n8n은 자격 증명(Credential)에 넣었다.
  2. [됨 · 아직 · 모름] 워크플로우 JSON을 남에게 줄 때 노드에 직접 적은 주소·chat id·이메일·개인정보가 없다(자격 증명의 키 값은 JSON에 들어가지 않는다).
  3. [됨 · 아직 · 모름] 키가 노출된 것 같으면 발급한 곳에서 키를 지우고 새로 만든다.

C. 개인정보가 남는 곳

  1. [됨 · 아직 · 모름] n8n 실행 기록에는 입력한 이름·연락처가 그대로 남고, 요금제에 따라 정해진 기간 보관된다(체험·Starter 기준 7일). 운영 때는 워크플로우 Settings에서 Save successful production executions를 Do not save로 바꾸는 것을 검토한다(시험이 끝난 뒤).
  2. [됨 · 아직 · 모름] 구글 시트·Gmail·캘린더·텔레그램에도 같은 내용이 남는다. 보관 기간과 삭제 담당을 정했다.
  3. [됨 · 아직 · 모름] AI 안내문·요약을 위해 이름·민원 내용이 Gemini(구글)로 보내진다는 것을 안다. 꼭 필요한 칸만 보낸다.
  4. [됨 · 아직 · 모름] n8n Cloud는 유럽연합(EU) 지역 서버에 데이터를 둔다. 국외 보관을 포함해 기관 개인정보 담당과 협의한다.
  5. [됨 · 아직 · 모름] 민원인에게 수집·이용 동의를 받는다(앱의 동의 칸 문구를 기관 양식에 맞춘다).

D. 운영 환경과 승인

  1. [됨 · 아직 · 모름] 기관 보안 담당·개인정보 담당과 협의한 뒤 적용한다. 협의 전에는 가상 데이터로만 시범 운영한다.
  2. [됨 · 아직 · 모름] 교육용 n8n Cloud 체험 계정·개인 구글 계정은 운영에 쓰지 않는다. 운영 환경(기관 설치형 n8n 또는 승인된 서비스)을 전산 담당과 정한다.
  3. [됨 · 아직 · 모름] 기관 설치형 n8n 무료판의 사용 조건(Sustainable Use License)을 법무·전산 부서가 확인했다.
  4. [됨 · 아직 · 모름] 동시에 접수하면 접수번호가 겹칠 수 있다. 운영 전에 보완 방법을 정했다.
  5. [됨 · 아직 · 모름] AI가 쓴 안내문·요약은 초안이다. 사람이 확인한 뒤 보내는 절차를 정했다.

E. 교육이 끝난 뒤 정리

  1. [됨 · 아직 · 모름] 필요 없는 앱은 AI Studio 왼쪽 Apps 목록에서 지웠다.
  2. [됨 · 아직 · 모름] 필요한 워크플로우는 … → Export JSON으로 내려받고, 나머지는 Unpublish 또는 삭제했다.
  3. [됨 · 아직 · 모름] 연습 시트·메일·캘린더 일정·텔레그램 봇을 정리했다.
