# 접수 완료 화면에 AI 안내문 함께 보여 주기

- 사용 교시: d2-p1 (2일차 1교시 앱 ↔ n8n 연동 ②)
- 전제: n8n `앱에 답하기`가 `{"접수번호": "...", "메시지": "...", "안내문": "..."}`를 돌려준다(`docs/data-contract.md` 응답 표, d2-p1 이후).
- 앱은 d1-p4 템플릿대로 `접수번호`·`메시지`만 보여 주므로 `안내문`을 보여 주도록 한 번 요청한다.

## 복사할 프롬프트

### 안내문 표시하기

```text
n8n이 이제 {"접수번호": "...", "메시지": "...", "안내문": "..."} 모양의 JSON을 돌려줘. 접수 완료 화면에서 "메시지" 아래에 "안내문"을 여러 줄 그대로(줄바꿈 유지) 보여 줘. 안내문이 없거나 비어 있으면 그 칸은 보이지 않게 해 줘. 입력 칸 이름과 WEBHOOK_URL은 바꾸지 마.
```

### 기다리는 동안 안내 (AI 안내문 때문에 답이 늦을 때)

```text
접수하기를 누른 뒤 답이 올 때까지 버튼 아래에 "접수 중입니다. 안내문을 만드는 데 10초쯤 걸릴 수 있습니다."를 보여 줘. 입력 칸 이름과 WEBHOOK_URL은 바꾸지 마.
```

## 바꿀 자리

- 없음.

## 예상 결과

- 접수하면 완료 화면에 접수번호, "접수되었습니다", 그 아래 4~6문장 안내문이 보인다.
- 안내문은 AI가 쓴 초안이다. 실제 운영에서는 담당자가 확인한 뒤 민원인에게 보낸다(d2-p1 교안의 주의 박스).
