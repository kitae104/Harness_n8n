# 오류 대처 루틴 — 연습용 오류 만들기와 오류 신고 문장

- 사용 교시: d1-p5 (1일차 5교시), 이후 모든 AI Studio 실습에서 반복 사용
- 루틴: **① 오류 글 찾기 → ② 오류 신고 문장을 먼저 입력창에 붙여 넣기 → ③ 오류 글을 복사해 `오류:` 아래에 끼워 넣고 보내기 → ④ 미리보기로 확인** (순서가 중요: `Ctrl`+`C`는 마지막에 복사한 것 하나만 기억한다)
- 오류는 수강생 잘못이 아니다. AI가 만든 코드는 가끔 틀린다. 루틴대로 알려 주면 AI가 고친다.

## 복사할 프롬프트

### 오류 신고 문장 (가장 중요 — 앞으로 계속 씀)

```text
아래 오류가 났어. 원인을 쉬운 말로 한 줄 설명하고 고쳐 줘. 입력 칸 이름과 WEBHOOK_URL은 바꾸지 마.

오류:
(여기에 복사한 오류 문구를 붙여 넣기)
```

### 연습용 오류 만들기 (5교시 연습에서만 사용)

#### 연습 1 — 버튼을 누르면 나는 오류

```text
연습을 위해 일부러 오류를 하나 만들어 줘. "접수하기" 버튼을 누르면 화면에 오류 문구가 뜨도록, 버튼을 눌렀을 때 실행되는 코드 안에서 존재하지 않는 함수를 부르게 바꿔 줘. 오류는 고치지 말고 그대로 둬. 다른 부분은 바꾸지 마.
```

#### 연습 2 — 열자마자 보이는 오류

```text
연습을 위해 일부러 오류를 하나 더 만들어 줘. 이번에는 앱이 열리자마자 미리보기에 오류가 보이도록, 화면을 그리는 코드에서 닫는 괄호 하나를 지워 줘. 오류는 고치지 말고 그대로 둬. 다른 부분은 바꾸지 마.
```

### 되돌리기 문장 (수정이 마음에 들지 않을 때)

`Restore` 같은 되돌리기 버튼은 어느 요청의 것을 누르느냐에 따라 여러 단계가 한꺼번에 사라질 수 있어, 수업에서는 이 문장을 기본으로 쓴다.

```text
방금 바꾼 것을 되돌려서 바로 전 상태로 돌아가 줘.
```

### 끝내 안 고쳐질 때 (복구 문장)

```text
연습용으로 만든 오류를 모두 없애고, 오류 연습 요청을 보내기 전 상태로 되돌려 줘. 입력 칸 이름과 WEBHOOK_URL은 바꾸지 마.
```

## 바꿀 자리

- `(여기에 복사한 오류 문구를 붙여 넣기)`: 미리보기나 대화창에 보인 오류 글을 그대로 붙여 넣는다. 영어여도 그대로 붙여 넣는다.

## 예상 결과

- 연습 1: `접수하기`를 누르면 오류 문구(예: `… is not defined`)가 보인다.
- 연습 2: 미리보기가 비거나 오류 화면이 보인다.
- 대화창에 오류를 고치는 버튼(예: `Fix errors`)이 나타나면 눌러도 된다(F8, 미확인). 없거나 눌러도 그대로면 오류 신고 문장을 쓴다.
- 오류 신고 문장을 보내면 AI가 원인을 한 줄로 설명하고 고친다. 미리보기가 다시 4교시 화면처럼 동작한다.
- AI가 연습용 오류 만들기를 거절하거나 오류를 곧바로 스스로 고쳐 버리는 경우가 있다(→ fact-check F84). 이때는 교안(d1-p5) 안의 "연습용 오류 문구"를 복사해 ①~③ 동작만 연습한다.
- 대화창에 `An internal error occurred. Retry.`처럼 AI 쪽 오류가 뜨면 앱 코드 오류가 아니다. 잠시 뒤 같은 요청을 다시 보낸다.
