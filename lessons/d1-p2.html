학습목표

  • 트리거–처리–결과 3단 구조로 워크플로우를 읽고, 표현식 {{ }}로 앞 노드의 값을 가져다 쓸 수 있습니다.
  • 구글 시트 기록, Gmail 발송, Gemini 안내문 작성을 한 워크플로우로 실행합니다.
  • 완성본 JSON을 가져오고 자격 증명을 다시 연결할 수 있습니다.

왜 이 단계가 필요한가

오늘 오후에는 앱 화면에서 들어온 민원을 n8n이 받아 처리합니다. 이때 받은 뒤의 처리, 곧 시트에 적고 메일을 보내고 안내문을 쓰는 부분은 기초과정에서 만든 것을 거의 그대로 씁니다. 바뀌는 것은 맨 앞의 시작 신호 하나뿐입니다. 그래서 오전에 이 처리 부분을 다시 손에 익혀 둡니다.

노드와 노드 사이로 값을 넘겨주는 것이 표현식({{ }} 안에 써서 앞 노드의 값을 가져오는 문장)입니다. 손으로 옮겨 적지 않고 앞 단계가 이미 알고 있는 값을 가져다 쓰기 때문에, 이름이 뒤바뀌는 실수가 생기지 않습니다.

표현식가져오는 값이 워크플로우에서의 결과
{{ $json.이름 }}앞 노드(샘플 민원)의 이름 칸홍길동
{{ $json.종류 }}앞 노드의 종류 칸생활
{{ $now.toFormat('yyyy-MM-dd') }}지금 이 순간의 날짜실행한 날의 날짜(예: 2026-09-22)
한 문장 요약 시작 신호(트리거)만 바꾸면 뒤의 일은 그대로 돌아갑니다. 오후에는 수동 실행과 샘플 민원 자리에 앱이 들어옵니다.
모든 결과 노드가 샘플 민원에 직접 이어진 이유 노드를 하나 지나면 넘어가는 값이 그 노드의 결과로 바뀝니다. 예를 들어 시트에 기록 뒤에 메일 노드를 이으면 메일 노드는 민원 내용이 아니라 "기록 결과"를 받게 됩니다. 그래서 세 결과 노드를 모두 샘플 민원에서 부챗살처럼 갈라 이었습니다.

따라하기

오늘은 모두 같은 완성본에서 시작합니다 기초과정 내용을 잘 기억하는 분도, 오랜만인 분도 1·2단계에서 같은 파일을 가져옵니다. 처음부터 다시 만드는 대신, 연결하고 실행하고 고쳐 보면서 기억을 되살립니다. 10단계까지가 필수이고, 11단계는 시간이 되는 만큼 합니다.
  1. 완성본 내려받기 아래 단추를 누릅니다. 파일은 보통 내 PC의 다운로드 폴더에 저장됩니다. 복습 완성본 내려받기 d1-p2.json
  2. n8n에 가져오기 n8n 첫 화면 오른쪽 위 Create workflow를 누릅니다. 빈 캔버스가 열리면 오른쪽 위 … → Import → From file을 누르고, 다운로드 폴더에서 d1-p2.json을 고릅니다.

    왼쪽부터 수동 실행, 샘플 민원, 세 갈래(시트에 기록, 접수 메일 보내기, AI 안내문 작성), 그리고 AI 안내문 작성 아래 작은 동그라미 Google Gemini Chat Model까지 노드 6개가 보이면 성공입니다. 몇몇 노드의 경고 표시는 정상이며, 4~9단계에서 연결합니다.

  3. 기록할 구글 시트 준비하기 먼저 브라우저 오른쪽 위 동그란 프로필 사진을 눌러, 준비물로 만든 개인 구글 계정으로 로그인돼 있는지 확인합니다. 4단계에서도 같은 계정을 고릅니다.

    새 탭 주소창에 sheets.new를 입력하고 Enter를 눌러 새 구글 시트를 만듭니다. 왼쪽 위 제목 없는 스프레드시트를 눌러 이름을 민원대장 연습으로 바꿉니다. 첫째 줄 A1 칸을 누르고 아래 줄을 복사해 붙여 넣으면 여섯 칸에 나뉘어 들어갑니다.

    이름	연락처	이메일	종류	상세설명	등록일
    화면 아래쪽 탭 이름(보통 시트1)도 확인해 둡니다. 5단계에서 씁니다. 강사 확인 F72한국어 구글 계정에서 새 시트 첫 탭 이름이 시트1인지(영어 계정은 Sheet1)

    첫째 줄에 여섯 단어가 한 칸씩 들어가면 성공입니다.

    자주 하는 실수

    증상 실행했는데 시트의 일부 칸이 비어 있어요
    원인 머리글 글자가 워크플로우와 달라요(예: 상세 설명처럼 띄어 씀)
    해결 머리글을 위 여섯 단어와 한 글자도 다르지 않게 고치세요

  4. 시트에 기록에 구글 계정 연결하기 시트에 기록 노드를 두 번 눌러 엽니다. 맨 위 Credential 칸을 누르면 보이는 Create new credential(화면에 따라 Connect to …)을 누르고, Sign in with Google → 3단계에서 확인한 계정 선택 → 허용 순서로 진행합니다. 구글 로그인 창이 뜨지 않으면 주소창 오른쪽의 팝업 차단 표시를 눌러 허용하세요. 허용 화면에 체크 칸이 있으면 모두 체크합니다.

    이렇게 만든 연결을 자격 증명(n8n이 내 구글·텔레그램 계정을 대신 쓰도록 맡겨 둔 열쇠)이라고 합니다. Account connected가 보이면 성공입니다. 자격 증명 창 오른쪽 위 X로 닫으면 시트에 기록 설정 창으로 돌아옵니다. 강사 확인 F59설정 창을 닫고 캔버스로 돌아가는 방법(창 바깥 누르기 / Back to canvas) 표기

    자주 하는 실수

    증상 구글 로그인 창에서 오류가 나거나 허용 버튼이 없어요
    원인 기관 계정(@korea.kr 등)은 외부 앱 연결이 막혀 있을 수 있어요
    해결 준비물로 만든 개인 구글 계정으로 다시 시도하세요

    증상 5단계 목록에 내 시트가 없거나, 실행하면 권한 오류가 나요
    원인 시트를 만든 구글 계정과 n8n에 연결한 구글 계정이 달라요
    해결 시트 오른쪽 위 프로필 사진으로 계정을 확인하고, 같은 계정으로 시트를 새로 만들거나 자격 증명을 다시 연결하세요

  5. 내 시트 고르기 시트에 기록 설정 창에서 Document 칸 왼쪽 작은 목록을 눌러 From list로 바꾸고, 목록에서 민원대장 연습을 고릅니다. Sheet 칸에 이미 시트1이 들어 있고 3단계에서 본 탭 이름도 시트1이면 그대로 둡니다. 다르면 칸 왼쪽 목록을 From list로 바꾸고 내 탭 이름을 고릅니다. 목록에 시트가 없으면 By ID로 두고 여기에_본인_시트_ID를 지운 뒤, 시트 주소 가운데 /d/와 /edit 사이의 긴 글자(시트 ID)를 붙여 넣습니다.

    아래쪽에 이름~등록일 여섯 칸이 fx 표시와 함께 보이면 성공입니다. 창 바깥 빈 곳을 눌러 캔버스로 돌아갑니다.

  6. Gmail 연결하기 접수 메일 보내기를 두 번 눌러 열고 4단계와 같은 방법으로 같은 구글 계정을 연결합니다(Gmail용 자격 증명이 따로 하나 생깁니다).

    Credential 칸에 Gmail 자격 증명 이름이 보이면 성공입니다. 창 바깥 빈 곳을 눌러 캔버스로 돌아갑니다.

  7. 받는 사람 바꾸기 샘플 민원을 두 번 눌러 엽니다. 이메일 칸의 본인이메일@example.com을 지우고, 6단계에서 연결한 내 Gmail 주소를 중괄호 없이 그대로 적습니다. 접수 메일 보내기의 To 칸이 {{ $json.이메일 }}이라서, 여기 적은 주소로 메일이 갑니다.

    이메일 칸에 내 Gmail 주소가 보이면 성공입니다.

    자주 하는 실수

    증상 실행은 초록색인데 메일이 오지 않아요
    원인 샘플 민원의 이메일이 본인이메일@example.com 그대로라 없는 주소로 보냈어요
    해결 이메일 칸을 내 Gmail 주소로 바꾸고 다시 실행하세요

  8. Gemini 연결하기 AI 안내문 작성 아래 점선으로 매달린 작은 동그라미 Google Gemini Chat Model을 두 번 눌러 엽니다. Credential 칸에서 Create new credential을 누릅니다. Use Gateway credits와 Use my own credential 선택지가 보이면 Use my own credential을 고릅니다. API Key 칸에 준비물에서 발급받은 API 키(Gemini를 쓸 수 있게 해 주는 비밀 번호표)를 붙여 넣고, Host는 그대로 둔 채 저장합니다. 키를 적어 둔 곳을 못 찾으면, 키를 발급받았던 화면(aistudio.google.com/apikey)에서 다시 복사할 수 있습니다. 강사 확인 F74aistudio.google.com/apikey에서 이미 만든 키를 다시 복사할 수 있는지

    저장한 뒤 연결에 성공했다는 표시가 보이면 성공입니다. X로 자격 증명 창을 닫습니다. 강사 확인 F73Gemini 자격 증명 만들기 화면 순서·버튼 글자, 저장할 때 연결 성공 표시

    API 키는 비밀번호처럼 API 키가 보이는 화면을 찍어 공유하거나 메신저로 보내지 마세요. 남이 내 키로 Gemini를 쓸 수 있습니다.
  9. 모델 고르기 같은 창의 Model 칸에 이미 이름이 적혀 있어도, 목록을 열어 models/gemini-3.8-flash를 한 번 더 누릅니다. 목록에는 내 API 키로 쓸 수 있는 모델만 보이기 때문에, 내 키로 다시 골라 두는 것입니다.
    자주 하는 실수

    해결 자격 증명을 열어 API 키를 다시 붙여 넣으세요. models/gemini-3.8-flash가 없으면 models/gemini-3.5-flash-lite를 고르세요

  10. 실행하고 결과 세 곳 확인하기 열려 있는 창을 모두 닫고 캔버스로 돌아온 뒤, 아래쪽 Execute workflow를 누릅니다.

    모든 노드에 초록색 표시가 생기면, 아래 세 곳을 확인합니다.

    • 구글 시트 민원대장 연습에 홍길동 민원 한 줄이 생겼나요?
    • 내 Gmail(받은편지함에 없으면 스팸함도)에 제목이 민원 접수인 메일이 왔나요?
    • AI 안내문 작성 노드를 열었을 때 오른쪽 결과에 안내문이 보이나요?
    메일 본문이 담당팀께로 시작하는 것은 기초과정 본문을 그대로 쓴 것입니다. 실습에서는 결과 확인을 위해 내 주소로 받습니다.
    빨간 노드가 생겼을 때 빨간 노드를 두 번 눌러 열면 오른쪽에 오류 글이 보입니다. 시트에 기록이면 3~5단계, 접수 메일 보내기면 6·7단계, AI 안내문 작성이나 Google Gemini Chat Model이면 8·9단계로 돌아가 확인하세요. 오류 글에 사용량 초과(quota) 같은 말이 있으면 Model을 models/gemini-3.5-flash-lite로 바꾸고 다시 실행하세요. 강사 확인 F75Gemini 한도 초과 때 노드 오류 문구(quota 등), 가벼운 모델로 바꾸면 실행되는지
    AI 안내문은 초안입니다 AI는 사실이 아닌 내용도 그럴듯하게 쓸 수 있습니다. 처리 기한·담당 부서·법령 같은 내용은 반드시 사람이 확인한 뒤 보냅니다.

    여기까지 오면 이 교시의 필수는 끝났습니다.

  11. 표현식과 샘플 민원 고쳐 보기 이름·연락처에는 본인이나 지인의 실제 정보 대신 가상 이름(홍길동·김민원 등)만 씁니다.

    ① 접수 메일 보내기를 열고 Subject 칸에 마우스를 올려 Expression을 누릅니다. 칸을 누르고 Ctrl+A로 글자를 모두 고른 뒤 Delete로 지우고, 아래 글을 붙여 넣습니다.

    [{{ $json.종류 }}] 민원 접수 - {{ $json.이름 }}

    ② 샘플 민원을 열어 이름을 김민원, 종류를 음식물, 상세설명을 매주 화요일 음식물 쓰레기 수거가 되지 않고 있습니다.로 바꿉니다.

    ③ 창을 닫고 다시 Execute workflow를 누릅니다. 시트에 줄이 하나 더 생기는 것은 정상입니다.

    시트의 새 줄과 AI 안내문이 김민원·음식물 내용으로 바뀌고, 메일 제목이 [음식물] 민원 접수 - 김민원이면 성공입니다. 재료(샘플 민원)를 바꾸면 결과 세 곳이 함께 바뀝니다. 오후에는 이 재료를 앱이 채웁니다.

    자주 하는 실수

    증상 메일 제목에 {{ $json.종류 }} 글자가 그대로 찍혀요
    원인 Subject 칸이 표현식 모드가 아니라 글자 그대로(Fixed) 모드예요
    해결 칸에 마우스를 올려 Expression을 누르세요. 칸 왼쪽에 fx가 보이면 표현식 모드입니다

시간이 남으면: 안내문 규칙 바꿔 보기 AI 안내문 작성을 열면 Prompt (User Message) 칸에 AI에게 시키는 글, 곧 프롬프트(AI에게 시키는 일을 적은 문장)가 있습니다. [작성 규칙] 아래 - 존댓말을 사용하고, 4~6문장으로 작성합니다. 줄에서 4~6문장으로를 3문장 이내로로 고치고 실행해 안내문이 어떻게 달라지는지 보세요.

확인 문제

객관식Q1. 오후에 앱과 연결할 때 바뀌는 부분은?

  1. 시트에 기록
  2. 접수 메일 보내기
  3. 수동 실행과 샘플 민원(시작 신호와 재료)
  4. AI 안내문 작성
정답 확인

정답: ③ 결과를 만드는 노드는 그대로 두고, 시작 신호와 재료만 앱에서 오도록 바꿉니다.

단답형Q2. {{ $json.종류 }}는 11단계를 마친 뒤 어떤 값이 될까요?

정답 확인

정답: 음식물 — 샘플 민원의 종류 칸 값을 가져옵니다.

정리

  • 워크플로우는 트리거(시작 신호) → 처리(재료 준비) → 결과(시트·메일·안내문)로 읽습니다.
  • 표현식 {{ $json.이름 }}은 앞 노드의 값을 가져다 쓰는 방법이고, 칸 왼쪽의 fx로 확인합니다.
  • 재료(샘플 민원)를 바꾸면 결과 세 곳이 함께 바뀝니다.
  • 다음: 3교시에는 이 워크플로우의 새 시작 신호가 될 Webhook을 만듭니다.

완성본 가져오기(Import)

중간에 꼬였다면 새 워크플로우에 완성본을 다시 가져와 10단계 실행까지 마친 상태로 돌아갈 수 있습니다. 11단계(메일 제목, 김민원)는 가져온 뒤 다시 해 보세요.

  1. 파일 내려받기 워크플로우 내려받기 d1-p2.json
  2. n8n에서 가져오기 Create workflow → 오른쪽 위 … → Import → From file을 누르고 파일을 고릅니다.
  3. 자격 증명 다시 연결하기 아래 세 노드를 차례로 열어 Credential 칸에서 이미 만들어 둔 내 자격 증명을 고릅니다(없으면 따라하기 4·6·8단계처럼 새로 만듭니다).
    • 시트에 기록 — 구글 시트용
    • 접수 메일 보내기 — Gmail용
    • Google Gemini Chat Model — Gemini API 키
  4. 자리표시자 바꾸기
    • 시트에 기록의 Document: 여기에_본인_시트_ID 대신 목록에서 내 시트 고르기(시트가 없으면 따라하기 3단계대로 먼저 만듭니다), Sheet: 내 탭 이름(파일에는 시트1로 들어 있음)
    • 샘플 민원의 이메일: 본인이메일@example.com → 내 Gmail 주소
    • Google Gemini Chat Model의 Model: 목록에서 models/gemini-3.8-flash 다시 고르기
  5. 실행해 확인하기 Execute workflow를 눌러 시트·메일·안내문 세 곳이 채워지면 복구 완료입니다.
