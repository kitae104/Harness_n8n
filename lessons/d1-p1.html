목차 › 1일차 › 1교시 (09:00~09:50)

입과 안내 및 과정 소개

이틀 뒤에 손에 쥘 서비스를 먼저 봅니다 — 앱에서 접수하면 시트·메일·캘린더·AI 안내문까지

학습목표

  • 앱에서 민원을 접수하면 시트·메일·캘린더·텔레그램까지 이어지는 완성 서비스의 흐름을 말로 설명할 수 있습니다.
  • "화면은 AI가, 일은 n8n이" 역할 분담을 이해합니다.
  • 실습에는 가상 데이터만 쓴다는 원칙과 이틀간의 진행 방식을 압니다.
  • 사전조사한 자동화 희망 업무를 한 문장으로 공유합니다.

왜 이 과정이 필요한가

기초과정에서 n8n으로 민원 접수·기록·알림 자동화를 만들어 보셨습니다. 그런데 설문에서 가장 많이 나온 말은 "내 업무에 바로 쓰기는 어렵다"였습니다. 이유 하나는 입구가 없다는 것입니다. 워크플로우는 잘 돌아가도, 동료나 민원인이 들어와 내용을 적을 화면이 없으면 부서에서 함께 쓰기 어렵습니다.

이번 과정은 그 화면을 AI로 만들고, 기초과정에서 배운 n8n 자동화를 뒤에 붙여 하나의 서비스로 완성합니다.

역할누가하는 일
화면Google AI Studio(문장으로 앱 화면을 만들어 주는 구글의 무료 도구)입력 칸과 버튼이 있는 앱. 우리는 한국어 주문서만 씁니다
연결Webhook(외부 앱이 n8n을 부르는 주소)앱에서 누르면 n8n이 일을 시작하는 초인종
일n8n 워크플로우시트 기록, 메일, 캘린더, AI 안내문, 텔레그램 — 기초과정에서 배운 노드
한 문장 요약 화면은 AI가, 일은 n8n이 합니다. 우리는 코드를 한 줄도 쓰지 않고, 주문서를 쓰고 노드를 잇습니다.
개인정보 원칙 — 이틀 내내 지킵니다
  • 실습에는 교안에 나오는 가상 이름·연락처(홍길동, 010-1234-5678 등)만 씁니다.
  • 실제 민원 데이터, 공문, 동료·민원인의 실명과 연락처는 절대 넣지 않습니다. 입력한 값은 시트, n8n 실행 기록, AI 서비스에 남습니다.
  • 실제 부서에 적용하는 것은 2일차 3교시 점검표를 거쳐 기관 보안 담당과 협의한 뒤입니다.

활동

  1. 입과 안내 (5분) 강사·보조강사 소개, 쉬는 시간(매 교시 50분 수업 + 10분 휴식), 막혔을 때 손을 드는 방법을 안내합니다. 보조강사는 계정·권한 문제(구글 로그인, Gemini 키)와 오류 해결을 맡습니다.
  2. 완성 서비스 시연 (12분) 강사가 이틀 뒤의 완성본(2일차 2교시 결과)을 화면에 띄우고 차례로 보여 줍니다. 수강생은 따라 하지 않고 무엇이 어디서 일어나는지만 봅니다.
    1. 앱 화면에서 가상 민원(홍길동 / 010-1234-5678 / 생활 / 보도블록이 깨져 있습니다.)을 접수합니다.
    2. 앱에 접수번호(예: 2026-0922-001)와 AI가 쓴 안내문이 뜹니다.
    3. 구글 시트에 한 줄이 쌓입니다.
    4. 담당자 메일, 캘린더의 처리 마감 일정, 텔레그램 알림이 옵니다.
    5. 앱의 "처리 상태 조회"에 접수번호를 넣으면 처리 상태가 나옵니다.
    6. n8n 화면에서 이 모든 일을 한 워크플로우가 해냈다는 것을 보여 줍니다.
    강사 메모 시연 파일은 workflows/d2-p2.json입니다. 수업 전날 강사 계정 n8n Cloud에 가져와 계정 연결과 게시까지 마치고, 시연용 앱의 주소를 맞춰 둡니다(아래 "완성본 가져오기").
  3. 이틀 로드맵 (3분)
    시간1일차: n8n 다지기 + 첫 앱 + 연결2일차: 자동화 확장 + 내 업무 서비스
    1교시입과 안내·완성 서비스 시연담당자 메일·캘린더·AI 안내문
    2교시n8n 핵심 복습담당자 나누기·텔레그램·처리 상태 조회
    3교시Webhook 이해와 실습앱 배포·공유·보안
    4교시AI 앱 빌더 첫 체험내 업무 서비스 기획(설계서)
    5교시첫 앱 다듬기·오류 대처내 업무 서비스 제작 ①
    6교시앱 ↔ n8n 연동 ①내 업무 서비스 제작 ②
    7교시접수번호 회신·1일차 정리발표·피드백·적용 로드맵

    뒤처져도 괜찮습니다. 모든 교시 끝에 "완성본 가져오기"가 있습니다. 그 교시 끝 상태의 워크플로우 파일을 가져오면 다음 교시를 함께 시작할 수 있습니다.

  4. 준비물 점검 (10분) 아래를 하나씩 확인합니다. 안 되는 것은 바로 아래 "안 될 때" 박스를 보고, 그래도 안 되면 손을 듭니다. 보조강사가 돌아다니며 돕습니다.
    • 브라우저 오른쪽 위 프로필 사진을 눌렀을 때 보이는 이메일이 개인 Gmail인가요? (기관 메일이면 AI Studio나 구글 연결이 막힐 수 있습니다. AI Studio는 나이 확인이 된 성인 개인 계정만 쓸 수 있습니다)
    • n8n Cloud 계정에 로그인되나요? 무료 체험 기간이 이틀 안에 끝나지 않나요?
    • Gemini API 키(Gemini를 쓸 수 있게 해 주는 비밀 번호표)를 메모장 등에 저장해 두었나요?
    • aistudio.google.com/apps를 열었을 때 앱을 만드는 입력창이 보이나요?
    • 텔레그램 봇 토큰(내 알림 봇을 쓰는 비밀 번호)과 내 chat id(내 대화방 번호)가 있나요? 2일차 2교시에 씁니다. 없으면 기초과정 2일차 준비물을 보고 그 전까지 준비합니다.
    안 될 때
    • Gemini API 키가 없거나 어디 뒀는지 모르겠어요 → 개인 구글 계정으로 aistudio.google.com/apikey에 들어가 Create API Key를 누릅니다. 나온 키를 복사해 메모장에 붙여 넣고 바탕화면에 저장합니다. 2교시 시작 전까지만 있으면 됩니다.
    • n8n 체험 기간이 얼마나 남았는지 모르겠어요 → n8n 화면에 남은 기간 안내가 보이면 확인합니다. 이틀 이하로 남았거나 이미 끝났으면 보조강사에게 알립니다. 새 체험 계정을 만들어도 교시 끝 "완성본 가져오기"로 곧바로 따라올 수 있습니다.
    • 주소가 열리지 않아요(교육망 차단) → ① 주소 철자를 다시 봅니다. ② Chrome 브라우저로 다시 엽니다. ③ 그래도 안 되면 손을 듭니다. 강사가 준비한 다른 접속 방법으로 바꿔 드립니다. AI Studio는 4교시부터 쓰니 지금 안 열려도 1~3교시는 그대로 따라올 수 있습니다.
    비밀값은 나만 봅니다 API 키와 봇 토큰은 비밀번호와 같습니다. 화면을 찍어 공유하거나 메신저로 보내지 않습니다.
  5. 자동화 희망 업무 공유 (10분) 입과 전 사전조사에 적은 "자동화하고 싶은 업무"를 한 사람씩 1분 안에 말합니다. 
    나는 ○○ 업무에서, 지금은 ○○을 손으로 하는데, ○○이 저절로 되면 좋겠다.

    실제 민원인이나 동료의 이름, 실제 사건 내용은 말하지 않습니다. "민원 접수", "시설 점검"처럼 업무 이름으로만 말합니다.

    강사는 비슷한 업무끼리 칠판에 묶습니다(예: 신청 접수형, 현장 보고형, 문서 정리형). 이 묶음이 2일차 4교시 프로젝트의 팀과 주제가 됩니다.

    예: "나는 시설 점검 업무에서, 지금은 현장에서 사진 찍고 돌아와 보고서를 쓰는데, 현장에서 입력하면 팀장에게 바로 가면 좋겠다."

정리

  • 이틀 뒤에는 앱 → n8n → 시트·메일·캘린더·AI 안내문·텔레그램 → 앱으로 이어지는 서비스를 직접 만듭니다.
  • 실습에는 가상 데이터만 씁니다.
  • 뒤처지면 교시 끝 "완성본 가져오기"로 따라잡습니다.
  • 다음: 2교시에는 기초과정에서 배운 n8n을 완성본 하나로 빠르게 복습합니다.

완성본 가져오기(Import) — 강사 시연 준비

이 교시의 시연 파일은 과정 최종 완성본인 2일차 2교시의 파일입니다. 수강생은 가져오지 않아도 됩니다. 궁금한 분은 수업 뒤에 가져와 둘러봐도 됩니다(Publish(워크플로우를 게시해 주소가 항상 동작하게 하는 버튼)는 하지 않습니다).

  1. 파일 내려받기 최종 완성본 내려받기 d2-p2.json
  2. n8n에서 가져오기 Create workflow → 오른쪽 위 … → Import → From file.
  3. 자격 증명 다시 연결하기 가져오면 여러 노드에 경고 표시가 보이는데, 연결 전이라 정상입니다. 노드 열여덟 개가 보이면 성공입니다. 둘러보기만 할 때는 연결하지 않아도 됩니다. 시연처럼 실제로 돌려 보려면 구글 시트·Gmail·캘린더·Gemini·텔레그램을 쓰는 노드마다 Credential 칸에서 내 자격 증명(n8n이 내 계정을 대신 쓰도록 맡겨 둔 열쇠)을 고릅니다. 노드 이름과 자리표시자(여기에_본인_시트_ID, 본인이메일@example.com, 여기에_본인_채팅_ID)는 2일차 2교시 완성본 가져오기에 모두 적혀 있습니다.

둘러보기가 끝났으면 이 워크플로우를 지워 둡니다. 2일차에 같은 이름의 워크플로우가 둘 생기는 것을 막기 위해서입니다.
