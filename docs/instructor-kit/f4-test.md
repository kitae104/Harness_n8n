# 강사 시험 F4 — AI Studio 앱에서 n8n Webhook으로 POST가 되는가 (기본 15분 + 추가 10분)

d1-p6(앱 ↔ n8n 연동 ①) 이후 모든 연동 교시의 근거가 되는 시험이다. **시험하면서 체크할 동작은 [f4-checklist.html](f4-checklist.html)**(브라우저로 열거나 인쇄)에 단계별로 있다. 이 파일은 절차와 결과별 조치의 원본이다. 끝나면 맨 아래 **"대화에 붙여 넣을 결과"** 칸을 채워 Claude 세션에 그대로 붙여 넣는다. Claude가 결과에 따라 fact-check·교안을 고치고 FACT-CHECK 주석을 정리한다.

## 준비물 (시작 전 확인)

- [ ] 크롬 브라우저(교육장과 같은 환경이면 더 좋음 — 교육망 PC라면 적어 둔다)
- [ ] n8n Cloud 계정(수강생과 같은 무료 체험 계정이면 더 좋음)
- [ ] 1일차 4교시 주문서(`prompts/d1-p4-minwon-app.md`)로 만든 **민원 접수 앱** — 코드 맨 위에 `WEBHOOK_URL = ""`이 있는 것. 없으면 주문서를 AI Studio Build에 붙여 넣어 먼저 만든다(약 3분)
- [ ] 이 폴더의 `f4-test-workflow.json`(노드 2개: `앱에서 받기` → `앱에 답하기`, 경로 `f4-test`, CORS `*`)
- [ ] 가상 값: 홍길동 / 010-1234-5678 / minwon@example.com / 생활 / 시험

## 절차

### A. n8n 준비 (3분)
1. n8n에서 `Create workflow` → 오른쪽 위 `…` → `Import` → `From file` → `f4-test-workflow.json`. 노드 2개가 보이면 된다.
2. n8n 버전을 적어 둔다(왼쪽 아래 `Help` → `About n8n`, 또는 `Settings`). 모르면 비워 둔다.
3. `앱에서 받기`를 두 번 눌러 열고, 위쪽 `Test URL`을 고른 뒤 아래 주소를 한 번 누른다. `URL copied` 알림이 뜨면 복사된 것(F60). 설정 창을 닫는다.
   - ⚠️ 설정 창 안의 `Listen for test event`는 **누르지 않는다**. 그 노드만 실행되어 `앱에 답하기`가 돌지 않는다(F223).

### B. 앱에 주소 넣기 (3분)
4. AI Studio에서 민원 접수 앱을 열고 대화 입력창에 아래 문장을 넣는다. 따옴표 안에 복사한 Test URL을 붙여 넣고 보낸다. **AI의 수정이 끝날 때까지 기다린다.**
   ```
   코드 맨 위 WEBHOOK_URL 값을 "(복사한 Test URL)"로 바꿔 줘. 다른 부분은 바꾸지 마.
   ```
5. 미리보기에 가상 값을 모두 넣어 둔다(아직 `접수하기`는 누르지 않음).

### C. 시험 ① 미리보기 → Test URL (2분)
6. n8n 탭에서 **캔버스 아래 `Execute workflow`** 를 누른다. 여기서부터 2분 안에 7을 한다.
7. AI Studio 탭으로 가서 `접수하기`를 누른다.
8. 결과를 본다.
   - **성공**: 앱에 `TEST-001`과 "시험 성공 — 받은 이름: 홍길동 / origin: ○○○"이 보인다 → **origin 값을 그대로 적는다**.
   - **실패**: "접수하지 못했습니다" 등이 뜬다 → `F12` → `Console` 탭의 빨간 글을 복사한다. 글에 `CORS`, `Content Security Policy`, `blocked` 중 무엇이 있는지 적는다.
   - 어느 쪽이든 n8n 캔버스에 초록 표시가 생겼는지(= n8n까지 도착했는지) 적는다. 가능하면 `앱에서 받기` 출력의 `headers.origin`·`body`를 캡처한다.

### D. 시험 ② Production URL (3분)
9. n8n 위쪽 `Publish` → 확인 창에서 다시 `Publish`. 버튼 글자가 `Published`로 바뀌는지 본다(F61).
10. `앱에서 받기`를 열어 `Production URL`을 고르고 주소를 누른다(`URL copied`). 4의 문장으로 앱의 `WEBHOOK_URL`을 이 주소로 바꾼다.
11. n8n에서 아무것도 누르지 않고 앱에서 `접수하기` → 8과 같이 결과를 적는다.

### E. 추가 확인 (가능한 만큼, 각 2~3분)
12. **공유 링크**: AI Studio 오른쪽 위 `Share`로 링크를 만들어 크롬 시크릿 창(`Ctrl`+`Shift`+`N`)에서 연다. 로그인을 요구하는지 적고, 열리면 `접수하기` → 결과를 적는다(F3·F4).
13. **Allowed Origins를 좁혔을 때**: `앱에서 받기`의 `Allowed Origins (CORS)`를 `https://example.com`으로 바꾸고 `Publish`(버튼이 다시 `Publish`로 바뀌어 있음) → 앱에서 `접수하기`. 앱이 **실패하면 정상**이다. n8n `Executions`에 실행이 남았는지도 적는다(남든 안 남든 정상 — F143). 끝나면 `*`로 되돌리고 다시 `Publish`.
14. **우회 방법(8 또는 11이 실패했을 때만)**: AI Studio에 아래 문장을 보내고 11을 다시 한다(F80).
    ```
    n8n 주소 호출은 서버 쪽 코드에서 하도록 바꿔 줘. WEBHOOK_URL 값과 보내는 JSON의 키 이름은 바꾸지 마.
    ```
15. **(덤, 1분) d1-p3 확인** — 게시 중에는 Test URL이 등록되지 않을 수 있으므로 8 직후(Publish 전)나 16의 Unpublish 뒤에 한다: 설정 창 안 `Listen for test event`를 누르고 Test URL을 불렀을 때 앱(또는 주소창)에 빈 응답이 오는지. 교안은 이 경우를 "하얀 화면" 실수로 안내한다(F223).

### F. 정리
16. 시험이 끝나면 `Publish` 오른쪽 작은 화살표 → 목록 맨 아래 `Unpublish` → 확인 창에서 다시 `Unpublish`(F225). 시험용 워크플로우는 지워도 된다.
