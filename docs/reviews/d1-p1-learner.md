# d1-p1 수강생 관점 리뷰 (2026-09-25)

리뷰 관점: 54세 지방직 주무관, n8n 기초과정 수료(석 달 전), 프로그래밍 경험 없음, 영어 화면은 단어를 하나씩 맞춰 봄.
대상: `lessons/d1-p1.html`(activity), 시연 파일 `workflows/d2-p2.json`, 대조 `lessons/d2-p2.html#import`.

## 요약
- 막힘 3건 / 헷갈림 10건 / 사소 5건
- 가장 먼저 고칠 곳: **4단계 "준비물 점검"에 '안 될 때' 대처가 하나도 없음.** 질문("저장해 두었나요?", "열리나요?")만 있고, 아니라고 답한 수강생이 무엇을 하는지(API 키 만드는 곳, 체험 기간 확인·만료 시 대처, 교육망 차단 시 대안)가 없습니다. 작성 가이드의 `note planb`("막혔을 때") 박스로 항목별 대처를 붙여야 합니다.
- 잘된 점: "뒤처져도 괜찮습니다" 문단, "수강생은 따라 하지 않고 무엇이 어디서 일어나는지만 봅니다" 문장, 개인정보 원칙을 별도 박스로 둔 것, Webhook을 "초인종"에 빗댄 풀이. 첫 시간 불안을 줄이는 데 효과가 있습니다. 불안을 주는 말("간단히", "쉽게", "당연히", "누구나")은 없습니다.
