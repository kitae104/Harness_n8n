## 요약
- 막힘 3건 / 헷갈림 10건 / 사소 5건
- 가장 먼저 고칠 곳: 따라하기 2단계의 "보내기 버튼(또는 <kbd>Enter</kbd>)". 수강생은 영문 화면에서 보내기 버튼이 어디인지, 무슨 글자가 적혀 있는지 모릅니다. 여러 줄 글을 붙여 넣은 입력창에서는 <kbd>Enter</kbd>가 줄바꿈만 할 수도 있습니다(fact-checker 확인 필요). 그러면 첫 단계에서 멈춥니다. 강사 캡처로 버튼 이름과 위치를 확정해 문장과 [그림 1-4-1]에 넣어야 합니다. 그다음으로 고칠 곳은 "앱이 안 만들어지거나 미리보기에 오류가 날 때"(3단계)와 "Apps 목록에 내 앱이 없을 때"(6단계)입니다. 두 곳 모두 복구 경로가 없습니다.

## 시간 어림
- 개념 10분은 적당합니다(표 1개, 템플릿 세 부분, 박스 2개).
- 실습 6단계는 빠른 수강생 기준 20~25분입니다(접속·계정 확인 3분, 복사·생성 대기 5분, 확인·시험 5분, Code 탭 5분, Apps 3분).
- 느린 수강생은 첫 접속(동의 창·계정 전환, 6번)과 보내기 버튼 찾기(1번), `WEBHOOK_URL` 찾기(10번)에서 각 3~5분 더 걸려 **35~40분**으로 어림합니다. 점심 직후라 계정 문제로 시작이 늦는 사람도 있습니다. 1·6·10번을 고치면 30~35분 안에 들어올 것으로 봅니다.

## 좋았던 점
- 불안을 주는 말("간단히", "쉽게", "당연히", "누구나")이 본문에 없습니다. "누르기 쉽게"는 AI에게 주는 프롬프트 속 말이라 괜찮습니다.
- "옆 사람과 화면이 달라도 정상입니다"와 확인할 세 가지를 못박은 점, 퀴즈 Q1이 이를 다시 짚는 점이 불안을 크게 줄여 줍니다.
- "연결되지 않았습니다"가 뜨는 것을 성공으로 미리 알려 주어 실패로 오해하지 않습니다.
- 가상 값만 쓰고, 4단계 hint와 프롬프트 [넣지 말 것]에 실제 이름·연락처 금지가 두 번 들어 있습니다.
