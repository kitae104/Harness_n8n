# d1-p7 수강생 관점 리뷰 (2026-09-25)

검토 대상: `lessons/d1-p7.html`, `prompts/d1-p7-show-receipt.md`, `workflows/d1-p7.json`(Import 안내 대조), `lessons.json` d1-p7 명세. 참고: `lessons/d1-p6.html`, `lessons/d1-p3.html`(4·7단계 참조 확인), `docs/writing-guide.md`, `docs/glossary.md`, `docs/data-contract.md`, `docs/sample-data.md`.
관점: 54세 주무관, 오후 4시(하루 끝, 피곤함), 영어 화면은 단어를 하나씩 맞춰 봄, 인쇄본과 웹 교안을 함께 봄.

## 요약
- 막힘 4건 / 헷갈림 17건 / 사소 6건
- 가장 먼저 고칠 곳:
  1. **4단계 긴 표현식 복사**: 가로로 스크롤되는 한 줄 상자라 끝까지 끌어 고르기 어렵고, 인쇄본에서는 잘려서 아예 옮길 수 없습니다. 또 JSON 칸을 `Expression`으로 바꾸라는 말이 없습니다(5·6단계에는 있음).
  2. **5단계 Cell Format**: 화면 글자 없이 "n8n이 보낸 그대로 기록하는 쪽"이라고만 적혀 있어 영어 선택지 중 무엇을 골라야 할지 모릅니다.
  3. **Import 안내의 Unpublish 조건**: "따라 만들던 워크플로우를 Publish했다면"이라고 되어 있어, 7단계까지 못 간 수강생은 "Publish 안 했다"고 여기고 Unpublish를 건너뜁니다. 6교시에 Publish한 워크플로우는 지금도 게시 중입니다.
  4. 설정을 바꾸는 곳이 여섯 군데(시간대, Always Output Data, Execute Once, Cell Format, Respond, 다시 Publish)인데 한눈에 보는 점검표가 없고, 3~5단계는 중간 확인 없이 8단계에서 한꺼번에 드러납니다. 피곤한 시간이라 "어디서 틀렸는지"를 찾는 데 시간이 가장 많이 듭니다.

## 참고(문제 아님)
- 용어 풀이: Respond to Webhook, Publish, Production URL, 자격 증명, 표현식 모두 첫 등장에 `<dfn>`이 있습니다. "간단히/쉽게/당연히/누구나" 없음.
- 3교시 4단계(`Respond`), 7단계(`Response Body` Expression) 참조 번호가 실제 3교시와 맞습니다.
- Import 안내의 자격 증명 노드 이름(`오늘 접수 조회`, `시트에 기록`)과 자리표시자(`여기에_본인_시트_ID` 두 곳)가 JSON과 일치합니다. 시간대·Always Output Data·Execute Once·Cell Format(`RAW`)·`responseNode`도 JSON에 들어 있어 Import만으로 교시 끝 상태가 됩니다.
- 가상 데이터(박시민 / 010-0000-0003 / minwon@example.com)는 sample-data.md 허용 범위입니다. 제안한 최주민 / 010-0000-0004도 허용 범위입니다.
