## 시간 어림
- 개념 10분은 적당합니다(표 2개 + 박스 2개, 이미 배운 내용).
- 실습(느린 수강생 기준): 1단계 가져오기 4분, 2단계 시트 만들기·머리글 5분, 3단계 구글 로그인 5분, 4단계 시트 고르기 4분, 5단계 Gmail·이메일 5분, 6단계 Gemini 키·모델 6분, 7단계 실행·세 곳 확인 5분, 8단계 제목 3분, 9단계 샘플 바꾸기 4분 = **약 41분**. 구글 로그인이나 API 키 찾기에서 한 번 막히면 45분을 넘습니다. 개념 10분 + 정리 5분을 더하면 50분을 넘기므로, 15번 제안대로 8·9단계를 합치거나 9단계를 선택으로 돌리는 것이 좋겠습니다.
- 다만 "같은 완성본에서 시작"하는 설계 덕분에 만들기 시간은 없고, 느린 수강생도 7단계까지는 30분 안팎에 닿을 수 있습니다.

## 좋았던 점
- 불안을 주는 말("간단히", "쉽게", "당연히", "누구나")이 없습니다.
- 첫머리 tip("오늘은 모두 같은 완성본에서 시작합니다")이 오랜만에 온 수강생을 안심시킵니다.
- 부챗살 연결 이유, 기관 계정 막힘, 머리글 띄어쓰기, 예시 이메일 그대로 보내기, API 키 공유 금지, AI 초안 사람 확인 박스가 기초과정 경험과 잘 이어집니다.
- Import 섹션에 다시 연결할 노드 3개와 자리표시자(시트 ID·탭 이름·이메일·모델)가 모두 적혀 있습니다.
- 가상 이름(홍길동·김민원)만 쓰고, 9단계에 가상 이름 안내가 있습니다(위치만 앞으로 당기면 됨).
