# opt-voice 수강생 관점 리뷰 (2026-09-25)

읽은 파일: `lessons/opt-voice.html`, `prompts/opt-voice-input.md`, `lessons.json`(opt-voice), `docs/writing-guide.md`, `docs/glossary.md`, `docs/data-contract.md`, `docs/sample-data.md`, `docs/fact-check.md`(F217~F222), 대조용 `lessons/d1-p4·d1-p5·d1-p6·d2-p2.html`의 해당 부분.
이 교시는 n8n JSON을 새로 만들지 않고 `workflows/d2-p2.json`을 참조합니다(role `reference`). 인쇄 양식은 없습니다.

## 요약
- 막힘 3건 / 헷갈림 16건 / 사소 8건
- 가장 먼저 고칠 곳: ① 교육장 PC에 **마이크가 없거나 꺼져 있을 때** 안내가 전혀 없음(4단계에서 진도가 멈춤, 주문서에 `audio-capture` 오류 문구도 없음) ② 완성본 가져오기에 **예전 워크플로우 Unpublish 경고**가 빠져 있음(같은 `minwon` 주소라서 Publish가 안 될 수 있음) ③ 자율학습 수강생이 **앱 자체가 없을 때** 되돌아갈 길이 없음(Import는 n8n만 복구함)
- 분량: 느린 수강생 기준 실습 약 25분(앱 열기 5 / 주문·대기 5 / Code 탭 확인 3 / 권한·말하기 7~10 / 접수·시트 확인 3)입니다. 35분 안에 들어옵니다. 다만 완성본을 가져와 다시 연결해야 하면 15~20분이 더 들어서 2일차 6교시 프로젝트 시간을 잡아먹습니다. 그 점을 1단계 앞에 알려 주면 좋습니다.
- 불안을 주는 말("간단히", "쉽게", "당연히", "누구나")은 없습니다. 개념 블록의 개인정보 경고(말소리가 구글 서버로 감, 가상 문장만 말하기)는 충분합니다.
