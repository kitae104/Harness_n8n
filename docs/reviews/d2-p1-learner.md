# d2-p1 수강생 관점 리뷰 (2026-09-25)

## 요약
- 막힘 4건 / 헷갈림 9건 / 사소 8건
- 가장 먼저 고칠 곳: 8단계에 **어제 만든 AI Studio 앱을 다시 여는 방법**이 없습니다(아침이라 브라우저를 닫고 왔을 수 있음). 그다음은 6단계 **캘린더 자격 증명을 새로 만드는 과정**입니다. 창이 여러 번 바뀌는데 성공했는지 확인할 방법도, 실수 박스도 없습니다.
- 시간(느린 수강생 기준 어림): 아침 준비(로그인, 어제 워크플로우 찾기) 3분 + 1단계 2분 + 2단계 6분 + 3단계 3분 + 4단계 4분 + 5단계 6분 + 6단계 7분(구글 로그인 창 포함) + 7단계 2분 + 8단계 4분(앱 찾기, 다시 만들어질 때까지 기다리기) + 9단계 4분 = **약 41분**입니다. 실습 30~35분을 넘습니다. 9시 35분 기준 시각에 느린 수강생은 5~6단계쯤에 있습니다. 그때부터 가져오기(Unpublish, 자격 증명 다섯 개, 자리표시자 네 개, Publish)에 약 8분이 걸리고 8·9단계가 5~6분 걸려 50분 안에 끝나지 않습니다.
- 노드 추가 자체(1~6단계)는 흐름이 분명합니다. 하지만 2·5·6단계에 "성공입니다" 확인 문장이 없어서, 9단계에서 처음 시험해 보고 틀리면 어느 단계에서 틀렸는지 찾기 어렵습니다.
