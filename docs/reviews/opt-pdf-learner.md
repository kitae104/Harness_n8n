# opt-pdf 수강생 관점 리뷰 (2026-09-25)

읽은 파일: `lessons/opt-pdf.html`, `prompts/opt-pdf-upload-app.md`, `workflows/opt-pdf.json`, `assets/samples/gongmun-sample.html`, `lessons.json`(opt-pdf), `docs/writing-guide.md`, `docs/glossary.md`, `docs/data-contract.md`(opt-pdf 항목)
관점: 54세 주무관이 **혼자(수료 후 자율학습)** 인쇄본과 화면만 보고 따라 한다고 가정했습니다.

## 요약
- 막힘 3건 / 헷갈림 13건 / 사소 7건
- 가장 먼저 고칠 곳: 5단계(세 갈래 잇기). 한 단계에 노드 세 개를 만들고, "아래 첫 줄·둘째 줄·셋째 줄·넷째 줄"이 실제로는 **코드 상자 네 개**를 가리켜서 셋째 상자(세 줄짜리)를 어디에 넣을지 헷갈립니다. Gmail·텔레그램 자격 증명과 텔레그램 `Chat ID` 입력도 빠져 있습니다. 그다음은 6→7단계의 복사 순서(6단계에서 복사한 Test URL이 7단계에서 주문서를 복사하면서 지워짐)와 "빠른 길" 안내(자격 증명 연결을 건너뛰게 됨)입니다.
- 좋은 점: 가상 공문 파일을 따로 준비해 둔 점, 실제 공문을 올리지 말라는 경고, 스캔 PDF 설명, 교시 끝 Import 안내에 자격 증명 노드 이름·자리표시자·Publish가 모두 들어 있는 점. "간단히·쉽게·당연히·누구나" 같은 말은 없습니다.
