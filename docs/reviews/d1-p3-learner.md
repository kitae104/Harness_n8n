# d1-p3 수강생 관점 리뷰 (2026-09-24)

검토 파일: `lessons/d1-p3.html`, `workflows/d1-p3.json`, `lessons.json`(d1-p3), 기준 `docs/writing-guide.md`·`docs/glossary.md`·`docs/data-contract.md`·`docs/sample-data.md`
(프롬프트·인쇄 양식 없음. JSON 노드 이름 `Webhook`·`Respond to Webhook`, 경로 `hello`, GET, `responseMode=responseNode`, `allowedOrigins=*`는 교안 본문과 일치.)

## 요약
- 막힘 2건 / 헷갈림 11건 / 사소 5건
- 가장 먼저 고칠 곳: 따라하기 6단계. 한 번호 안에서 화면이 3번 바뀌고, `Response Body` 칸에 이미 들어 있을 수 있는 기본 글자를 지우라는 말이 없습니다. 그래서 붙여 넣은 글이 기본 글자와 섞여 답장이 깨질 수 있습니다(fact-checker 확인 필요). 이와 함께 Import 섹션에 "먼저 만들던 워크플로우와 주소(`hello`)가 겹칠 때" 안내를 넣어야 합니다.

## 시간 어림
- 개념 10분은 적당합니다(표 1개 + 두 주소 설명 + 박스 2개).
- 실습 9단계는 빠른 수강생 기준 25분 안팎입니다. 느린 수강생은 6단계(Expression 찾기·붙여 넣기)와 7단계(2분 안에 탭 오가기, 재시도)에서 각각 5분 이상 더 걸려 **35~40분**으로 어림합니다. 3·11번을 고치면 30~35분 안에 들어올 것으로 봅니다.

## 좋았던 점
- 불안을 주는 말("간단히", "쉽게", "당연히", "누구나")이 없습니다.
- Test URL/Production URL, Respond 기본값, Publish 다시 누르기, GET/POST 실수 박스가 필요한 곳에 있습니다.
- 가상 이름(홍길동·김민원)만 쓰고 있고, 체크리스트 1번이 CORS입니다.
