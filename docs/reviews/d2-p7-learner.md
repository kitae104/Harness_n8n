# d2-p7 수강생 관점 리뷰 (2026-09-25)

리뷰 대상: `lessons/d2-p7.html`, `print/forms/roadmap.html` (함께 대조: `lessons/d2-p4.html`, `lessons/d2-p6.html`, `print/forms/design-sheet.html`, `lessons.json` d2-p3·d2-p7 명세)
관점: 54세 주무관, 프로그래밍 경험 없음, 사람들 앞에서 발표하는 것이 부담스럽고 6교시에 앱 연결을 끝내지 못했을 수도 있는 수강생.

## 요약
- 막힘 2건 / 헷갈림 11건 / 사소 5건
- 가장 먼저 고칠 곳: (1) 시간 합계가 55분(개념 10 + 준비 5 + 발표 25 + 로드맵 10 + 설문 5)으로 50분을 넘고, 발표 25분은 교대 시간 없이 5팀까지만 들어갑니다. 팀 수에 따른 진행 방법이 없습니다. (2) 시연이 안 되거나 6교시를 못 끝낸 수강생에게 "캡처로 설명합니다" 한 문장뿐입니다. 캡처도 없는 사람, 앱이 반쯤 된 사람이 무엇을 보여 주면 되는지 막혔을 때 박스(`note planb`)가 필요합니다.
