## 요약
- 막힘 3건 / 헷갈림 17건 / 사소 8건
- 가장 먼저 고칠 곳: **2단계·7단계의 복사 순서.** 교안대로 "주소 복사 → AI Studio로 가서 문장 붙여 넣기"를 하면, 문장을 복사하는 순간 방금 복사한 주소가 지워집니다. 복사한 것은 한 번에 하나만 기억된다는 것을 모르는 수강생은 여기서 멈춥니다. "문장 먼저 붙여 넣기 → 주소 복사 → 바꿔 붙이기" 순서로 바꿔야 합니다.
- 전체 느낌: 흐름(시험 → 시트 → Publish → 실제 사용)과 연결 점검표는 좋습니다. 다만 한 단계 안에서 탭을 두세 번 오가는 곳이 많고(1·2·3·5·6·7단계), 느린 수강생 기준으로 따라하기만 35~40분이 걸립니다. 우회 방법(서버 쪽 호출)까지 가면 50분을 넘깁니다. "15시 30분까지 ○단계를 못 끝냈으면 Import" 같은 기준이 필요합니다.

## 잘된 점(유지)
- 3단계에서 "앱 입력 먼저 → Listen → 접수하기" 순서로 2분 제한을 피하게 한 점.
- 필드 대응표(앱 → `민원 정리` → 시트 열)와 `body.이름` 실수 박스가 정확히 자주 틀리는 곳을 짚습니다.
- 연결 점검표 다섯 줄은 7교시 이후에도 계속 쓸 수 있습니다.
- JSON의 노드 이름(`민원 받기`·`민원 정리`·`시트에 기록`), 경로 `minwon`, 자리표시자 `여기에_본인_시트_ID`, 탭 `시트1`이 교안 Import 안내와 일치합니다. 2교시 `시트에 기록`이 `{{ $json.이름 }}` 형태라 복사해 붙여도 그대로 동작하는 구조입니다.
- 가상 인물(홍길동·김민원·이접수)과 번호는 모두 `docs/sample-data.md`에 있습니다. "간단히/쉽게/당연히/누구나" 표현은 없습니다.
