대상: `lessons/d2-p3.html`, `print/forms/security-checklist.html` (workflow 없음, prompts 없음)
관점: 54세 주무관, 영어 화면은 단어를 맞춰 봐야 찾음, 2일차 2교시에서 조금 뒤처졌을 수 있음.

## 요약
- 막힘 5건 / 헷갈림 14건 / 사소 6건
- 가장 먼저 고칠 곳: **3단계 `key`·`token` 찾기** — AI Studio 앱 코드에는 `GEMINI_API_KEY`, `key=` 같은 글자가 거의 항상 들어 있어서 "아무것도 나오지 않으면 성공"을 절대 만족할 수 없습니다. 수강생은 "내 앱에 키가 새어 나갔다"고 겁을 먹고 멈춥니다. 다음은 **점검표에 '모름/협의' 표시 칸이 없는 것**, **2단계 실수 박스가 아직 배우지 않은 6교시 표를 가리키고 주소 끝 설명이 틀린 것**입니다.
- 보안 개념 전달: "세 가지만 기억합니다" 박스와 '금고' 비유는 겁주지 않고 잘 전달됩니다. 다만 CORS 박스(따라하기 맨 뒤)와 기관 설치형 박스는 전문 용어(서버 쪽 코드, Header Auth, Docker, HTTPS, Google Cloud Console)가 한꺼번에 나와 "나는 못 하는 일"로 느껴지고, "주소가 알려지면 누구나 요청을 보낼 수 있다"는 말에 안심시키는 한 줄이 없습니다.
- 점검표: 혼자 읽을 수는 있지만 **혼자 표시하기는 어렵습니다.** □ 하나뿐이라 "모른다/교육 중엔 해당 없음/협의 필요"를 나타낼 방법이 없고, 사실을 알려 주는 문장(A-4)과 해야 할 일(D-4)이 섞여 있으며, 풀이 없는 용어가 많습니다.
