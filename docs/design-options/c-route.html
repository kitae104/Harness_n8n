1일차6교시, 15:00~15:50

앱 ↔ n8n 연동 ①

앱에 n8n 주소를 넣고, 앱에서 접수한 민원이 구글 시트에 한 줄로 쌓이게 합니다.

학습목표

  • 앱에 n8n Production URL을 넣어 접수 데이터를 보낼 수 있습니다(Test URL로 먼저 시험한 뒤).
  • 받은 데이터가 구글 시트에 한 줄로 기록되는 것을 확인합니다.

왜 이 단계가 필요한가

지금까지 세 조각을 따로 만들었습니다. 2교시의 일하는 워크플로우, 3교시의 초인종인 Webhook, 4·5교시의 창구 화면인 앱입니다. 이번 시간에 이 셋을 이어 붙여, 앱에서 누른 접수가 시트까지 가게 합니다.

  1. 새 워크플로우에 민원 받기 만들기

    n8n에서 Create workflow를 누르고 Webhook 노드를 추가합니다.

    • HTTP Method: POST
    • Path: 글자를 모두 지우고 minwon만 적습니다
    • Allowed Origins (CORS): *

    설정 창 위쪽 주소가 …/webhook-test/minwon으로 끝나면 이 역에 도착한 것입니다.

  2. 앱에 Test URL 넣기

    아래 문장을 AI Studio 입력창에 붙여 넣고, {Test URL} 자리에 n8n에서 복사한 주소를 넣은 뒤 보냅니다.

    AI Studio에 보낼 말
    코드 맨 위 WEBHOOK_URL 값을 "{Test URL}"로 바꿔 줘. 다른 부분은 바꾸지 마.

    Code 탭의 WEBHOOK_URL에 webhook-test 주소가 보이면 도착입니다.

  3. 첫 시험 — 앱에서 보내 보기

    Listen for test event를 누르면 n8n은 2분 동안만 기다립니다. 앱 입력을 먼저 끝내 두고, 누른 뒤 곧바로 앱의 접수하기를 누릅니다.

    자주 하는 실수
    증상
    n8n에 아무것도 오지 않아요
    원인
    2분이 지났거나, 주소가 틀렸거나, CORS 설정이 빠졌어요
    해결
    세 가지를 차례로 확인하고 다시 보냅니다
    우회 경로: 세 가지가 다 맞는데도 안 되면AI Studio에 “n8n 주소 호출은 서버 쪽 코드에서 하도록 바꿔 줘”라고 보낸 뒤 다시 시험합니다. 그래도 안 되면 손을 들어 강사에게 알립니다.

    OUTPUT의 body에 다섯 값이 보이면 도착입니다.
