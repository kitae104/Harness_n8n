교안 사이트 디자인 시안 4가지

네 시안 모두 같은 내용(첫 화면 + 1일차 6교시 교안 일부)으로 만들었습니다. 각 시안을 열어 “성공 확인” 버튼, 복사 버튼, 휴대폰 폭에서의 모습을 직접 눌러 보고 비교해 주세요.

A. 캔버스 — n8n 편집 화면 그대로

단계 하나가 노드 하나입니다. 성공을 확인하면 실행된 노드처럼 초록 테두리가 켜집니다. 첫 화면에서는 완성 워크플로우가 한 번 실행됩니다.

강점
수업 중 보는 n8n 화면과 교안이 같은 말투라 옮겨 다닐 때 덜 헷갈림
약점
n8n이 아닌 AI Studio 단계도 노드 모양이라 조금 어색함
부품
실수 = 오류 노드 창, 막혔을 때 = 캔버스 스티커 메모
시안 A 열기

B. 행정 서식 — 공문과 결재 도장

첫 화면은 과정 안내 공문, 교안은 서식 한 장입니다. 1. 가. 1) 번호, 서식 표, 문서 끝 “끝.”을 씁니다. 단계를 마치면 빨간 확인 도장이 찍히고 결재란이 채워집니다.

강점
공무원 수강생에게 가장 익숙한 문서 형식, 인쇄 교재와 가장 잘 맞음
약점
딱딱하게 느껴질 수 있음, 화면(프로젝터)에서 글자가 빽빽해 보임
부품
실수 = ※ 유의사항, 막혔을 때 = 조치 방법, 요청문 = 서식 칸
시안 B 열기

C. 노선도 — 이틀 과정을 지하철 노선으로

1일차·2일차가 두 노선이고 교시가 역입니다. “지금 여기”가 한눈에 보입니다. 교안의 단계는 정차역이고, 막혔을 때는 점선 우회 경로로 표시합니다.

강점
전체 흐름과 현재 위치를 가장 쉽게 파악, 프로젝터에서도 선명함
약점
n8n다운 느낌은 약함(흐름·연결이라는 공통점만 가져옴)
부품
실수 = 노란 주의 표지, 요청문 = 남색 안내판, 이전·다음 = 역 안내판
시안 C 열기

D. 실습 노트 — 강사가 펜으로 적어 준 공책

모눈 종이 위에 교안을 쓰고, 왼쪽 여백에 손글씨 도움말을 둡니다. 성공 조건은 형광펜, 요청문은 오려 붙이는 쪽지, 단계는 펜으로 체크합니다. 시간표는 학교 시간표 모양입니다.

강점
처음 배우는 사람에게 가장 친근하고 겁을 덜 줌, 강사 한마디를 넣기 좋음
약점
장식이 많아 보일 수 있음, 손글씨 글꼴은 짧은 말에만 써야 함
부품
실수 = 빨간 펜 동그라미, 막혔을 때 = 메모지, 캡처 = 테이프 붙인 사진
시안 D 열기
