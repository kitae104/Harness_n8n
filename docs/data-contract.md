# 데이터 약속 (data-contract)

여러 세션에 걸쳐 교시를 따로 쓰더라도 **앱 ↔ n8n ↔ 시트가 같은 이름을 쓰도록** 정한 약속이다.
누적 체인(`d1-p6 → d1-p7 → d2-p1 → d2-p2`)과 프로젝트 예시(`d2-p5 → d2-p6`)는 반드시 이 표를 따른다.

- 상태 `초안`: 해당 교시 세션에서 확정한다. 확정하면 `확정`으로 바꾸고 `docs/decisions.md`에 기록한다.
- **확정된 뒤 바꾸려면** 앞 교시 JSON·교안·프롬프트를 모두 함께 고쳐야 한다. 사용자에게 먼저 묻는다.
- verify.py는 체인 JSON의 Webhook 경로(`path`)가 이 표와 같은지 검사한다(아래 "Webhook 경로" 표를 읽음).
- 필드 이름은 기존 교안(PublicFlow `day1-08.json` 민원 입력 폼)을 이어받았다. 수강생이 선행 과정에서 쓴 `{{ $json.이름 }}` 같은 표현식을 그대로 쓸 수 있다.

## 민원 접수 — 앱이 보내는 값 (POST 본문, JSON)

n8n에서는 `{{ $json.body.이름 }}`처럼 `body` 아래로 들어온다(→ fact-check F26 확인 후 확정).

| 키 | 예 | 필수 | 비고 |
|---|---|---|---|
| `이름` | 홍길동 | Y | 가상 인명만(sample-data.md) |
| `연락처` | 010-1234-5678 | Y | |
| `이메일` | minwon@example.com | N | 민원인 안내 메일용 |
| `종류` | 생활 | Y | `생활` / `음식물` / `대형` 중 하나(기존 교안과 같음) |
| `상세설명` | 보도블록이 깨져 있어요 | Y | |

> **확정(D39, 4회차)**: Webhook 바로 뒤에 `민원 정리`(Edit Fields) 노드를 두어 `{{ $json.body.이름 }}` 등 다섯 값을 꺼낸다.
> 이후 노드는 기존 교안처럼 `{{ $json.이름 }}`으로 쓰고, 결과 노드는 모두 `민원 정리`에서 부챗살로 갈라 잇는다(기존 교안 결정 1).

## 민원 대장 — 구글 시트 열

시트 문서: d1-p2에서 만든 `민원대장 연습`을 이어서 쓴다. 탭: `시트1`(d1-p2와 같음). **확정(D39)**

| 열 | 채우는 교시 | 값 |
|---|---|---|
| `접수번호` | d1-p7 | `YYYY-MMDD-NNN` (glossary 참조) |
| `등록일` | d1-p2·d1-p6 | `{{ $now.toFormat('yyyy-MM-dd') }}` (기존 교안과 같은 이름·형식, D39) |
| `이름` `연락처` `이메일` `종류` `상세설명` | d1-p6 | 앱이 보낸 값 그대로 |
| `처리상태` | d1-p7 | `접수` → `처리중` → `완료` (접수 시 `접수`) |
| `담당자` | d2-p2 | 아래 담당자 배정표 |
| `처리마감` | d2-p1 | 접수일 + 3일(기존 교안 캘린더 규칙과 같음) |

## 응답 — Respond to Webhook이 앱에 돌려주는 값 (JSON)

| 교시 | 키 | 예 |
|---|---|---|
| d1-p7 | `접수번호`, `메시지` | `{"접수번호":"2026-0922-017","메시지":"접수되었습니다"}` |
| d2-p1 이후 | 위 + `안내문` | Gemini가 쓴 안내문(4~6문장) |
| d2-p2 조회 | `접수번호`, `처리상태`, `담당자`, `처리마감` | 없는 번호면 `{"오류":"접수번호를 찾을 수 없습니다"}` |

조회 요청: `GET …/minwon-status?접수번호=2026-0922-017` (초안 — 한글 쿼리 키가 앱·n8n에서 문제없는지 d2-p2 세션에서 확인)

## 담당자 배정 (d2-p2, If 분기)

| 종류 | 담당자(가상) | 메일 수신 주소(JSON 자리표시자) |
|---|---|---|
| 생활 | 정담당 | `본인이메일@example.com` |
| 음식물 | 강처리 | `본인이메일@example.com` |
| 대형 | 윤행정 | `본인이메일@example.com` |

수강생 실습에서는 모든 담당자 메일이 **본인에게** 오도록 한다(결과 확인용). 기존 교안 08강은 `생활인가?` If 노드 하나로 두 갈래(생활 / 그 외)를 나눴다. 세 갈래로 나눌지는 d2-p2 세션에서 정한다.
