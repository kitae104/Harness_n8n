# 실습용 가상 데이터 (허용 목록)

실습·예시·캡처·JSON에는 **이 파일에 등록된 가상 데이터만** 쓴다. 실제 민원 데이터·공문·실명·실제 연락처는 금지한다.
`scripts/verify.py`는 아래 표를 읽어 허용 목록으로 쓴다. 새 가상 인물이 필요하면 **먼저 여기에 추가**한 뒤 교안에 쓴다.

## 검사 규칙 요약 (verify.py)

| 대상 | 허용 | 실패 |
|---|---|---|
| 휴대전화·일반전화 | 아래 "허용 전화번호" 목록, `010-0000-0000`~`010-0000-9999` | 그 밖의 모든 전화번호 패턴 |
| 주민등록번호 패턴 | 없음 | `######-#######` 형태 전부 |
| 이메일 | `@example.com` `@example.org` `@example.net` 도메인, `{본인 이메일}` 자리표시 | 그 밖의 모든 이메일 주소 |
| 인명 | 아래 "허용 인명" 목록, `{...}` 자리표시, `{{ ... }}` 표현식 | **인명 필드**(`성명` `신청자` `민원인` `담당자`) 바로 뒤에 온 미등록 이름 |

- 인명 검사는 `성명:`, `신청자:`, `민원인:`, `담당자:` 형태와 표에서 해당 머리글 바로 옆 칸, JSON에서 키 이름이 정확히 그 네 단어인 값을 본다.
  `이름:` 전체는 검사하지 않는다(`서비스 이름:` 같은 오탐 방지).
- 인명 필드 뒤 값이 `팀` `과` `실` `국` `부` `센터` `반`으로 끝나면 부서명으로 보고 넘어간다.
- API 키·텔레그램 봇 토큰처럼 보이는 문자열도 실패로 처리한다(워크플로우 JSON 포함).

| 김민원 | 민원인 예시 |
| 이접수 | 민원인 예시 |
| 박시민 | 민원인 예시 |
| 최주민 | 민원인 예시 |
| 정담당 | 담당자 예시(도로·교통) |

## 가상 민원 예시 문장

- 도로: "OO동 주민센터 앞 보도블록이 깨져 있어 보행이 위험합니다."
- 환경: "매주 화요일 음식물 쓰레기 수거가 되지 않고 있습니다."
- 기타: "주민자치 프로그램 신청 방법을 알고 싶습니다."

지명은 `OO동`, `△△로`처럼 특정되지 않게 쓴다.
